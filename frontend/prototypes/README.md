# Protótipos — Kanda System

Este diretório contém protótipos HTML de desktop (versão early-stage).
Os protótipos são estáticos e foram gerados por ferramentas de wireframing.

**Versão canónica**: `prototypes/_desktop/`

## Notas

- Estes protótipos são **referências visuais**, não o frontend funcional.
- O frontend real está em `frontend/src/app/` (Next.js App Router).
- Cópias duplicadas foram removidas em Julho 2026.
